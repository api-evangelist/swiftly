# Swiftly

> Swiftly (Swiftly Systems, Inc.) is a Seattle-based retail technology company selling an AI
> platform for grocery, convenience and wholesale retail. It builds white-labeled shopper
> mobile apps and websites for regional and independent retailers and runs a multi-retailer
> closed-loop retail media network. Swiftly publishes no public developer program: there is
> no developer portal, no API reference and no SDK. The shopper-facing GraphQL API that
> backs its retailer apps is nonetheless anonymously introspectable.

Generated by the API Evangelist enrichment pipeline on 2026-08-05. Swiftly does not publish
an llms.txt of its own (https://swiftly.com/llms.txt returns 404). Everything below was
either fetched from Swiftly's public surface or derived from the introspected schema — no
part of it is a Swiftly claim about its API.

## API

- [Swiftly Shopper GraphQL API](https://prod.swiftlyapi.net/graphql): 45 queries, 11
  mutations, 308 types. Covers offers and coupons, product catalog and barcode lookup,
  store and chain directories, digital circulars, loyalty programs, rewards and challenges,
  shopper accounts and age verification, and retail-media ad placements. Undocumented;
  introspection is enabled for anonymous callers.
- [Health endpoint](https://prod.swiftlyapi.net/health): returns build version and commit.

## What is not there

- No developer portal, documentation site or API reference.
- No OpenAPI, AsyncAPI, or gRPC/protobuf definition.
- No published SDK or CLI on npm, PyPI, Maven, NuGet, RubyGems, Packagist or crates.io.
- No /.well-known/ document of any kind on any Swiftly host.
- No A2A agent card and no MCP server.
- No changelog, deprecation policy, SLA, status page, or rate-limit policy.
- No idempotency contract on any of the 11 mutations.
